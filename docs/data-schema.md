## 6. Player positions over time

- There is **no dedicated movement/tick event** in the GRID feed.
- Almost every event carries `seriesState`. With `includesFullState=true` it is the full snapshot; otherwise it is **trimmed** to the current game only, with keys: `games[].clock`, `games[].id`, `games[].segments`, `games[].sequenceNumber`, `games[].teams`. Both forms include `games[].teams[].players[].position` = `{x, y}` for all players.
- `includesFullState=true` only on: `freezetime-ended-timeout`, `freezetime-started-timeout`, `game-ended-round`, `game-started-gameClock`, `game-started-round`, `grid-ended-feed`, `grid-started-feed`, `player-completed-plantBomb`, `round-ended-freezetime`, `round-started-freezetime`, `series-ended-game`, `series-started-game`, `tournament-ended-series`, `tournament-started-series`.
- Acting players also carry their own position: `actor.state.game.position` (and `target.state.game.position` for player→player events).
